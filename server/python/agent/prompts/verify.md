## 회복 확인 단계

조치 직후 15초 창의 메트릭(첫 값이 기준 안이면 조금 뒤 다시 잰 `confirm`도)이 주어진다. 이 수치만으로 회복 여부를 판단한다.

- `error_rate`는 0~1 비율이다. 0이면 에러가 없다. `null`이면 조치 후 요청 메트릭이 아직 수집되지 않은 것이므로 회복으로 보지 않는다.
- `p95_seconds`는 초 단위다. `null`이면 지연 기준은 판단하지 않는다.
- `error_rate`가 기준(0.2) 미만이고 `p95_seconds`가 기준(1초) 미만이거나 `null`이면 첫 줄에 `RECOVERED`, 아니면 `NOT_RECOVERED`라고 쓴다.
- `confirm`(조금 뒤 다시 잰 값)이 있으면 그 값도 같은 기준으로 본다. 둘 다 기준 안이어야 `RECOVERED`다.
- 둘째 줄에 확인한 수치를 한 줄로 적는다. 예: `에러율 0.00 (기준 0.20), p95 0.08초 (기준 1초)`
