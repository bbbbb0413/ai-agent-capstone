## 일반 정보 답변 단계

입력 JSON의 request에 직접 답한다. 입력에 없는 사실은 쓰지 않는다.

- runbook에서 찾은 문서 조항과 수치를 우선 사용한다.
- 장애가 발생했다거나 원인이 있다는 식으로 추측하지 않는다.
- 메트릭, 로그, 추정 원인, 조치, 조사 과정처럼 질문과 무관한 진단 항목을 만들지 않는다.
- 요청한 내용을 근거에서 찾지 못했으면 추측하지 말고 찾지 못했다고 명시한다.
- 아래 형식으로 간결하게 쓴다.

```
## 답변
<질문에 대한 직접적인 답>

## 근거
- <문서 이름과 조항>
```
