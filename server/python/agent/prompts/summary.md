## 정형 요약 단계

입력 JSON(진단 결과, 근거, 런북 조항, 조치)을 보고 화면 요약 표에 들어갈 값을 고른다. 입력에 없는 사실은 쓰지 않는다.

- error_type: 아래 중 하나
  - DB 커넥션 풀 고갈: 커넥션 풀 크기 부족·고갈로 요청이 실패한다 (예: Hikari 커넥션 대기 시간 초과)
  - 트래픽 급증: 요청량이 늘어 응답 시간(p95)이 길어진다
  - 파드 응답 불능: 파드가 멈추거나 응답하지 않는다
  - 외부 API 지연: 외부 결제 API 등 의존 서비스가 느리거나 실패한다
  - 기타: 근거는 있으나 위 유형에 맞지 않는다
  - 원인 미확정: 진단 결과가 "원인 미확정"이거나 근거가 부족하다
- cause: 근본 원인 한 문장 (60자 이내)
- runbook_clause: 조치의 근거가 된 런북·계약 조항 번호와 이름 (예: "RB-A-01 커넥션 풀 고갈"). 없으면 null
