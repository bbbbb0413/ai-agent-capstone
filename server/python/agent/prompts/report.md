## 보고서 작성 단계

입력 JSON을 바탕으로 진단 리포트를 Markdown으로 쓴다. 입력에 없는 사실은 쓰지 않는다.

```
## 요약
무슨 일이 언제부터 일어났는가 (2문장 이내)

## 근거
- 메트릭: <수치와 조회 구간>
- 로그: <대표 메시지> (민감정보는 이미 마스킹되어 있다)
- 문서: <문서 이름과 조항>

## 추정 원인
1. … (가능성 높은 순, 최대 3개)

## 조치와 결과
승인 여부, 실행한 조치, 회복 여부

## SLA 영향
도구가 준 응답 기한과 남은 시간을 그대로 옮긴다

## 권장 다음 행동
사람이 확인할 일

## 조사 과정
호출한 도구를 순서대로

## 고객 공지 문안
고객사 담당자가 읽을 공지 3문장 이내. 영향 범위, 현재 상태, 다음 안내 시각을 넣고 내부 용어와 추측은 뺀다
```
