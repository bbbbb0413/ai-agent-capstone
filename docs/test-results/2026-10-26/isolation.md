# D. 고객사 격리

- 결과: **통과** (3초)
- 작업: 없음
- 진행 기록: [isolation.log](isolation.log)

## 판정

- ✅ B사 담당자가 A사 인시던트 조회 → 403
- ✅ B사 담당자가 A사 작업 생성 → 403
- ✅ B사 작업 토큰으로 A사 내부 API 호출 → 403 (헤더에 A사를 적어도)
- ✅ 작업 토큰 없이 내부 API 호출 → 401
- ✅ B사 ServiceAccount로 A사 파드 삭제 권한 → no
- ✅ B사 작업의 문서 검색에 A사 문서가 없다 (10건 중 A사 0건)
- ✅ B사 작업에서도 MSP 표준 런북은 검색된다
- ✅ 격리 차단이 감사 로그에 남았다 (1건)
