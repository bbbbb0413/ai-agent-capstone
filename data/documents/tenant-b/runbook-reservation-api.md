# B사 reservation-api 장애 대응 런북

가상 데모 문서다. 실제 고객사 문서가 아니다.

## RB-B-01 외부 결제 API 지연

- 증상: p95 응답시간 1.5초 이상, 로그에 `payment API timeout` 경고 반복
- 확인: 지연이 결제 요청에만 몰리는지, 결제 대행사 상태 페이지에 공지가 있는지 본다
- 조치: MSP가 직접 고칠 수 없다. 고객사 공지를 보내고 결제 대행사 문의는 고객사가 진행한다
- 금지: 계약상 서비스 재시작과 커넥션 풀 조정은 허용되지 않는다

## RB-B-02 고객 공지 기준

- Silver 등급이므로 장애 인지 후 1시간 안에 첫 공지를 보낸다
- 외부 업체 원인이면 업체 이름은 밝히지 않고 "외부 결제 연동 지연"으로 적는다
